# Accessibility — Family Risk Review

## Requirements

- TalkBack with logical focus order
- Descriptive content descriptions (no reliance on colour alone)
- Minimum touch targets ≈ 48dp; primary actions 52–56dp
- 200% font scaling without clipping / fixed-height text traps
- Sufficient contrast on light surfaces
- Reduced motion (system + in-app)
- Keyboard navigation where applicable
- Clear validation messages

## Custom visualisations

Household Support Map and Responsibility Timeline must expose meaningful semantics and equivalent readable summaries for assistive technologies. They must not be decorative-only canvases.

## Languages

Preserve Tamil and Hindi shaping; allow translated text to expand; test IME composition for all three languages.

## Phase 0 status

Theme, buttons, splash, and shell screens include basic semantics. Full audit is Phase 8.
